# Applied Data Science Course

This repository contains my coursework for the Applied Data Science course on Coursera, including the Jupyter notebooks prepared for the final capstone project.

## Final Capstone

The capstone notebooks document the project's data science workflow, analysis, code, and results. Supporting files, such as datasets, may also be included when needed.

## Using the Notebooks

View notebooks directly on GitHub or open them with Jupyter Notebook or JupyterLab. To run a notebook locally, install its required Python packages and ensure any referenced data files are available.
